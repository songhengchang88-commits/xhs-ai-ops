## 🎯 账号定位

- **内容形式：** 短视频为主（口播），图文为辅；AI 合成内容每条必勾声明
- **出镜形象：** 女性卡通版「东方甜美」定妆（半扎公主头 + 空气刘海 + 珍珠发夹、奶白针织短开衫），定妆图为唯一锚点，逐镜验收形象一致性
- **声线：** CosyVoice 克隆女声（零样本，基频约 258Hz），全程锁定不换
- **生产管线（定版）：** 文生图 → 图生视频（台词写进提示词，提示词只写运动/表演/单一运镜）→ 克隆声音轨按实测说话时间点对齐 → 字幕同轴（音字统一）；不手工变速、贴嘴、拼音轨
- **制作流程：** 先文字定死（口播稿 + 分镜表）→ 静图逐张验收 → 图生视频留时长余量 → 成片 ffprobe 验参 + 抽帧验看
- **发布节奏：** 每天 2 条（早帖约 07:16、晚帖约 20:16），巡查值班约 13:16 / 22:16

## 📝 内容矩阵

| 类型 | 作用 | 示例选题 |
|---|---|---|
| AI 工具测评 | 涨粉款 | 手机修图 3 神器，糊照一键变高清 |
| AI 效率技巧 | 引流款 | 原来 2 小时的工作，AI 10 秒就搞定了 |
| AI 实操/拆解 | 变现款 | 无实测不编收益：只做拆解/教程，不写「月入 X」 |

**收益表述红线：** 实操类必须有真实过程；无实测的改叫「拆解/教程」，禁止编造收益数字、禁止「保证月入 X」话术。

## 🧱 爆款笔记结构

钩子（前 3 秒给结果/痛点）→ 干货分条（每条一个工具/技巧，讲已查证的功能与免费口径）→ 评论区扣「想要」领免费清单 → 关注引导。标题公式：痛点 + 数字 + 结果，≤20 字。

## 🚀 发布流程

1. 选题打分 ≥12/20（见 01-选题库）才进生产
2. 分镜表定稿 → 静图验收 → 图生视频 → 配音对齐 → 字幕 → 验参抽帧
3. 创作平台（creator.xiaohongshu.com）网页端发布：标题/正文/标签（≤6 个，固定池）/AI 声明
4. 发布后发作者评论（讨论点 + 点名测工具钩子）
5. 24h / 72h 数据登记进 04-发布台账

## 💰 变现路径

1. **引流：** 评论「想要」→ 私信一对一发《AI 工具导航站》免费版（18 个工具）
2. **产品阶梯：** 免费 18 工具 → 9.9 付费版（50+ 工具 + 提示词库 + 教程）→ 39–69 专题包 → 199–399 小班陪跑 → 999+ 1 对 1（详见落地方案第十节）
3. **收款顺序：** 千帆/薯店站内店铺 ＞ 知识付费 SaaS ＞ 商户码过渡（类目资质由 Jason 核）

## ⚠️ 发布安全原则

- ❌ 不用第三方自动发布工具；不用 hubbe 的全自动发布代码（封号风险）
- ✅ Poly 用自带浏览器已登录会话半自动操作，像真人、低频、留痕
- ✅ 评论/私信不出现微信号、手机号、二维码、外链；不承诺收益；不刷评、不互赞、不买评论
- ✅ 遇平台警告/限流/验证码/登录失效：立即停发停回、保全证据、报 Jason；账号安全 > 当日 KPI
