## 一、目标与定位

- 店铺：小红书个人店「AI助理的店」
- 目标人群：大学女生 + 社会精英的年轻女性群体
- 定价路线：不卖大牌，走物美价廉、主要走量
- 品类：文具自营主线 + 服装自营（得体低退货软品类）+ 其他能做成视频、能吸流的品类（玩具等），跟着流量走

## 二、硬标准（缺一不可）

1. 源头厂（生产厂家，非经销批发）
2. 一件代发
3. 48 小时内发货 + 48 小时内揽收
4. 素材包＋小红书商用授权留证
5. 名义毛利 ≥40%
6. 袜类必须组套
7. 退货运费写进约定

## 三、品类方向与优先级

- 主推：打底裤（穿搭视频突出打底裤亮点）、袜子组套（堆堆袜/打底袜）
- 重点：帽子、纯色卫衣、短裙、上衣、鞋子（小白鞋）
- 文具：字帖、作业本（书行、大正已在售）
- 只做得体低退货软品类：得体款家居服、连裤袜打底袜、纯色卫衣、袜子组套
- 排除：连衣裙/裤装/羽绒服、情趣向、私密护理、美妆个护（个人店基本卖不了）

## 四、五问模板（每家必问）

1. 代发价/组套价
2. 48h 发货揽收 + 快递 + 密文面单
3. 素材包 + 小红书商用授权留证 + 平铺/实拍图
4. 实数运费（全国/偏远分档）
5. 7 天无理由 + 退货运费 + 面料成分与尺码表

## 五、判定与结案规则

- 实质回复 = 四问/五问至少答清三项；自动回复、表情、「嗯嗯」、「1」、「您好，稍等」不算
- 问询满 48 小时无实质回复即结案，不催复、不等待、不翻案
- 部分回复的商家最多一次补问；补问后仍不答齐即结案
- 授权被拒（明确不支持小红书商用授权）即刻结案
- 只做淘宝代发、不支持小红书的直接 pass
- 1688 按给定名查不到的直接 pass，不用换名再找
- 经销批发（非源头厂）不合格
- 注意：须走平台分销下单或第三方回流工具（聚水潭）的，小红书代发下单链路须另行确认是否走得通，不可只按旺旺口头推进
