# 07-周复盘

每周日晚 Poly 出一页简报，文件命名 `YYYY-Www.md`（如 2026-W45.md），内容固定五块：

1. 本周 TOP3 / BOTTOM3（标题 + 核心指标）
2. 新增爆款卡（角度/钩子句式/封面构图/评论区高频问题）
3. 下周排期建议
4. 被淘汰题型（同题型连续 3 条不及格 → 暂停 2 周）
5. 订单与售后汇总

## 判定口径

- 每条笔记 24h / 72h 各记一次：封面点击率、点赞率、收藏率（效率款主看）、评论「想要」数与私信数（实操款主看）、涨粉（测评款主看）、领取→成交转化
- 跑满 14 天后以账号中位数为基准：核心指标 ≥中位数 2 倍 = 爆款候选；≥中位数 = 及格；<中位数 50% = 不及格
- 爆款复制：7 天内连做 2 条同结构续集（换工具/换场景，不换结构）

首期复盘：账号 2026-11-05 起号，首期简报于 2026-11-09（周日）晚出。
